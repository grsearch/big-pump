# 已上链但账务待核对

交易成功并不保证钱包原生 SOL 净变化可以直接当作买入成本。账户关闭、WSOL、其他入账等资金流需要具体交易证据；不能以报价的 0.1 SOL 替代已核验成本，也不能因区块有效期已过把成功交易当失败重新买入。

对账异常现在持久化错误、最近检查时间、失败次数，并在实盘页面顶部展示。若 finalized 成功回执的目标币与 SOL 变化不符合核算条件，会保存本钱包的目标币变化、SOL 净变化和交易前后代币余额证据，区分“链上成功、账务待核对”和普通 RPC 请求失败。错误变化才新增事件，逐次检查仍保留审计。

程序继续对原签名重试对账，不重新广播。暂停新开仓仍可用，已入账持仓继续管理；待核对买入不会被虚构成正常持仓，其资产和成本没有计入持仓收益，尚不受自动止盈止损管理。必须完成资金核验才能准确接管。交易签名、交易 json（含 innerInstructions、pre/postBalances、pre/postTokenBalances、loadedAddresses）是核对所需资料，不需要私钥。

此改动只修复静默错误及证据缺失，没有自动推断正 SOL 净变化的资金来源。Bercd 个案仍需完整交易签名和实际资金流，不能仅根据外部诊断文字写入成本。
