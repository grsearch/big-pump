# 实时监控前置过滤

新入监控的 Stonk 币必须满足：`0 ≤ 链上毕业时间 − Stonk 官方 createdAt ≤ 20 分钟`。

列表发现先按官方时间初筛，最终入库再以已核验的链上毕业时间检查。WebSocket 比列表先收到迁移时，查询该 CA 的官方详情，并匹配池地址后读取创建时间；获取失败或时间缺失不会放行，沿用发现任务重试。超过 20 分钟的迁移记录为排除，不触发 X、Shadow 或实盘新信号。

20 分钟是创建到毕业的时长，不是程序发现延迟，也不是最长观察 AGE。进入后的观察 AGE 仍从毕业起计时，最长 24 小时。

更新不追溯删除已有观察记录或改变已有持仓退出规则。历史 FDV ≥1M 聪明钱包研究不受实时入场过滤影响。
