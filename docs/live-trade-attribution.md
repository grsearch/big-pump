# 实盘订单归属与路由

交易记录默认只显示实盘 C，可切换旧 A、未知或全部。已平仓收益及失败买入手续费按所选策略统计；当前持仓仍展示全部未平仓仓位，避免隐藏旧仓风险。跳过和失败尝试保留在订单明细，不算成功开仓。

新卖出订单继承持仓的策略。旧订单仅在 CA 与买入/卖出成交签名同时唯一匹配持仓时补策略，并记录证据；缺失或冲突不猜测。启动时补入账本，导出器也执行同一规则。历史无标识记录显示未知，不再默认认作旧 A。

新订单保存市场 Quote CA/名称、Jupiter 报价的输入输出资产、交换步骤和中间资产，持仓保留买卖两侧报价路径。路径只取白名单字段，不保存签名交易载荷。失败或跳过订单的报价并非成交证据。历史未保存路由不反推，也不把市场 Quote 硬当实际中间资产。所有详情提供目标币与链上成交入口；不凭报价声称钱包中间资产余额为零。

这些修改只补记账与展示，不增加 RPC 请求、不修改买卖条件或执行参数。
