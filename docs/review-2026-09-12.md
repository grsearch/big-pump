现有可靠结论：C 47 笔已平仓，22 笔移动止盈 +1.478226 SOL，25 笔 30 分钟超时 -2.094176 SOL。改变阈值会改变之后持仓及资金占用，不能把已知输家事后剔除当回测。应先积累新增 audit，用前段时间选参数、后段验证，并保留真实成交偏差和缺口。没有宣称找到最优阈值，也没有自动修改实盘阈值。

## 聪明钱包为什么为零
原导出不含 wallet/coverage 完整记录，不能给具体服务器下结论。代码还要求完整历史、成本可解释、足够样本；未支持 SWAP/转账、历史 SOL 汇率缺失、达到 50 页上限均可能卡在待核验。仅 AGE>30d、7d>20SOL 不足以自动成为已验证。新 dashboard 诊断和每日导出包含这些数据。原“每分钟一页”的吞吐问题已调整，无法解析的数据仍不冒充有效样本。

## 每日 COS 部署（在服务器项目目录执行）
每日北京时间 06:00，窗口 [前日06:00,当日06:00)，与服务器本地时区无关。systemd Persistent 用于错过时补跑最近一次；失败每 5 分钟重试。多天停机不会自动拆出所有漏掉日期，可用 --end-ms 指定历史窗口补导出，旧状态不是时间点快照。

```bash
python3 -m venv .export-venv
.export-venv/bin/pip install -r deploy/export-requirements.txt
# 创建权限为 600 的 .env.cos（不要放在聊天或 git 中）：
# COS_SECRET_ID=服务器已有密钥
# COS_SECRET_KEY=服务器已有密钥
# DATA_DIR=/实际项目绝对路径/data
sudo bash deploy/install-export.sh
```
可用 `EXPORT_PYTHON` 指定已有安装 COS SDK 的 Python。脚本不读取主交易 .env，不需要钱包私钥。导出脚本 --upload 才上传；不加该参数仅生成本地包。SQLite 使用在线备份，原库和签名交易不上传，上传对象 ACL 为 private，并下载回读 SHA-256。桶 guigu-1403019446 / na-siliconvalley，路径 big-pump/daily/。未在本地安装服务器定时任务，也未声称已成功上传；需服务器凭证和部署确认。

完整原始字段在 JSON，订单/持仓另有 CSV；包含跨期买入成本、观测流和清单。失败手续费从订单单列核算，避免重复。X charges 是 UTC 日账不能精确拆成 06:00 边界，明确标注。上下文和未平仓估值以实际备份时刻为准。
