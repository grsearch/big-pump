# 成交资金与持有人观察

此功能只采集与展示，不改变实盘入场或退出规则。

- 默认开启；`ENABLE_TOKEN_FLOW=false` 可停止新增成交扫描。
- 收录后 60 分钟内的 Stonk 池参与扫描，不依赖聪明钱包开关、FDV 或休眠状态。
- 全局每 5 秒最多处理一个池的 20 条签名，按最久未扫描顺序轮转，游标落盘。繁忙池或池子较多时可能积压；60 分钟结束后不再主动补扫。不能承诺全市场完整覆盖。
- 每笔只保存紧凑成交一次，按目标 mint + 交易签名去重。失败交易和普通转账不计成交；无法解析的交换计入覆盖诊断。
- 使用 Helius 顶层 swap 输入/输出计算钱包端金额，多跳中间资产不重复计入。缺少顶层 swap 时，仅接受现有严格净余额解析器能识别的单资产兑换。复杂多输入/多输出、部分赞助交易等仍可能无法解析。
- 金额为实际兑换资产数量乘交易当时已采集汇率，不含网络费用。USD 是同期估值，不是美元实际结算。缺汇率保留原始资产数量并标记未知；不使用未来汇率填补。
- “首次观察买家”只指本币采集样本中首次出现且为买入的地址，不证明此前零持仓。后补历史可能改变该分类。另列“新增持仓买入”：每轮最多核验两笔买单的链上 pre/postTokenBalances，本笔涉及的该钱包目标币账户余额由零转正才计入；其他未参与交易的账户可能已有持仓，也可能是清仓后重买，不能证明整个钱包首次持有。余额缺字段、RPC 失败或尚未核验均为未知，金额仅汇总已核验且有汇率的部分。
- 大额卖出为单笔钱包端卖出估值 ≥500 USD；阈值写入响应，未参与买卖决策。
- 详情按自然分钟对齐；价格变化为该分钟首末采样价。Holders 使用当时已采集、两分钟以内的数量。没有样本的分钟不填零，不能当作零买卖。

`flow-trade` 保存成交时间、接收时间、签名、钱包、方向、目标数量、兑换资产、兑换数量和当时汇率。`flow-scan` 保存扫描进度、错误和无法解析数量；审计另有紧凑 `flow-trade` / `flow-coverage` 记录。每日导出包含窗口内成交与扫描上下文，便于和已有行情/Holders 审计按时间对齐，回测必须尊重 receivedAt。

前端数据仅在打开代币详情时读取，不放进 dashboard 全量轮询。新增索引只覆盖紧凑成交记录；不会重新序列化钱包全历史。

部署需要更新代码、构建前端并重启 collector 与 dashboard。本地测试不会发起实盘交易。扫描使用现有 Helius 额度；新数据部署后才产生，旧导出包无法恢复原本缺失的成交。
