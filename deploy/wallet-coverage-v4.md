# 钱包核算覆盖 v4

本次涉及前端和 collector：测试、类型检查、构建后按现有部署方式更新相关服务。实盘参数不变；不运行任何历史导出或审计清理，不重装每日导出定时器。

旧 coverage parserVersion 会在下一次钱包扫描时升级为 4，从最新历史重新扫描；旧版 capped 钱包也能重新进入自动队列。保留交易及费用数据，用原签名去重更新，不删除数据库。扫描仍受每轮50页限制，完整历史没有补齐前不会验证通过。自动扫描需要原有 ENABLE_WALLET_RESEARCH=true；未开启时使用页面“重新核验 / 继续”。不要批量并发重扫全部钱包。

未解析兑换写入独立 wallet-issue，含钱包、签名和时间；只影响相关滚动窗口的完整收益。普通转账仍记录为未知成本，但没有对应未知卖出时不阻塞其他资产的已实现收益。若日后卖出该资产，即使转入早于7天，成本未知仍阻塞该次卖出的完整核算。无法解析的兑换不因笔数少被忽略。

已扫描完成的钱包点击“重新核验”会从头重新解析；已到分页上限的则继续原游标。自动刷新对完成的钱包只做增量扫描，避免反复全量查询。重新解析成功的签名删除对应 issue，并清除与交易内费用重复的额外钱包费用。保留年龄及收益验证门槛。

页面默认展示待核验钱包；完整收益不可用时显示“已核算部分”，这不是总收益或收益下限，不能据此宣称钱包达标。另显示近期未解析兑换和卖出成本未知的币数。验证：旧版覆盖重扫、无关空投不封锁、未知转入后卖出仍待核验、重解析后标记消失；不能用已验证数量大于零作为部署成功条件。
